# CopyPaste

CopyPaste хранит зашифрованную историю буфера обмена на macOS, Android, Windows и Linux.
Приложение поддерживает поиск, Quick Paste, управление приватной записью, сопряжение
устройств и необязательные модули OCR, семантического поиска, SMS-кодов и синхронизации
Supabase.

Скачайте последнюю версию на [GitHub Releases](https://github.com/dmytro-yevs/copypaste/releases).

## Установка на macOS

CopyPaste для macOS требует Apple silicon и macOS 14 или новее. Установите его через Homebrew:

```bash
brew tap dmytro-yevs/copypaste
```

```bash
brew install --cask copypaste
```

Или с помощью [скрипта установки](scripts/install.sh), который скачивает DMG выпуска,
сверяет его с опубликованной контрольной суммой SHA-256 и копирует `CopyPaste.app` в
`/Applications` или в `~/Applications`, если в `/Applications` нет прав на запись:

```bash
curl -fsSL https://raw.githubusercontent.com/dmytro-yevs/copypaste/main/scripts/install.sh | sh
```

Параметры передаются после `sh -s --`: `--version v0.1.0`, `--dir ~/Applications` или
`--dry-run`, чтобы скачать и проверить без установки.

CopyPaste не нотаризован, поскольку нотаризация Apple требует платного членства в Apple
Developer Program. Оба способа установки заново подписывают приложение локальным
сертификатом на вашем Mac, и оно открывается без запроса Gatekeeper. Если вы скачали DMG
в браузере, macOS заблокирует первый запуск: откройте
**Системные настройки → Конфиденциальность и безопасность** и выберите **Всё равно открыть**.

## Установка на Windows

После публикации CopyPaste в winget установите его на Windows (x64):

```powershell
winget install CopyPaste.CopyPaste
```

`winget upgrade CopyPaste.CopyPaste` обновляет приложение. Сопровождающим: см.
[настройку выпуска для Windows](packaging/windows/README.md) по подписи и публикации в winget.

## Организация истории

История поддерживает диапазоны дат по локальному календарю, быстрые периоды и
комбинированный серверный поиск с фильтрами по источнику, устройству, типу и тегам до
пагинации. У закреплённых элементов может быть несколько тегов; при откреплении назначенные
теги сохраняются. Определения тегов, назначения, состояние закрепления и порядок закреплённых
элементов синхронизируются через существующие зашифрованные P2P- и, при желании, облачные
транспорты, не изменяя время записи элемента.

Организация хранится отдельно от содержимого буфера обмена. Каждый тег, членство и
закрепление имеют независимую версию по принципу «побеждает последняя запись», включая
удаления, поэтому одновременные изменения разных назначений не перезаписывают друг друга.
Резервные копии включают организацию; текстовые экспорты содержат только содержимое буфера
обмена. Обновите все устройства, чтобы использовать функции организации. Старые клиенты
сохраняют организацию как непрозрачные неподдерживаемые двоичные записи, а не считают её
текстом, который можно вставить. Облачная синхронизация по-прежнему подчиняется настроенной
политике хранения на сервере.

## Модули

- **OCR** распознаёт текст на изображениях локально.
- **Семантический поиск** находит связанные элементы локально.
- **SMS-коды** копирует коды подтверждения из новых SMS-сообщений Android. Сам CopyPaste
  никогда не запрашивает доступ к SMS: это делает только **CopyPaste SMS** — отдельное
  небольшое приложение из того же выпуска, подписанное тем же ключом.
- **Синхронизация Supabase** синхронизирует зашифрованную историю через ваш проект Supabase.

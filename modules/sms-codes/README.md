# SMS Codes

SMS Codes is an optional Android module that recognizes verification and login
codes in new incoming messages. It copies only the recognized code into the
encrypted clipboard history and never imports older messages.

Install it from **Settings → Modules**, complete **Set up SMS access**, and enable
the module. SMS permissions belong only to **CopyPaste SMS**, a separate Android
app published with each release and signed with the same key; CopyPaste itself
requests none. It does not send, delete, or make either app the default SMS app.
Disable the module or uninstall CopyPaste SMS to stop SMS access.

# SMS Codes

SMS Codes is an optional Android module that recognizes verification and login
codes in new incoming messages. It copies only the recognized code into the
encrypted clipboard history and never imports older messages.

Install it from **Settings → Modules**, complete **Set up SMS access**, and enable
the module. It requires Android SMS permissions and does not send, delete, or
make CopyPaste the default SMS app. Disable or remove it to stop SMS access.

# Безопасность

Сообщайте об уязвимостях через приватный канал security advisory репозитория. Укажите
затронутую версию и платформу, шаги воспроизведения с синтетическими данными и последствия.

CopyPaste шифрует сохранённую историю, хранит ключи в хранилище ключей платформы и учитывает
маркеры приватного и конфиденциального буфера обмена, когда операционная система их
предоставляет. Для сопряжения оба устройства должны подтвердить один и тот же код. Модули —
это доверенные нативные расширения, работающие без песочницы.

Вывод OCR и семантического поиска выполняется локально. История буфера обмена
синхронизируется только с сопряжёнными устройствами или, если включено, через синхронизацию
Supabase. Синхронизация Supabase шифрует содержимое перед загрузкой. В режиме хранения файлов
копией файлы размером до 64 МиБ также загружаются как зашифрованные объекты с непрозрачными
именами и удаляются через 24 часа.
